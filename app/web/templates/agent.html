Hermes 早报推送 · 微信一条条收早报

把下面这段提示词整段复制发给 Hermes，它会按你的早报流水线顺序 把文字与长图一条一条推送到微信（iLink 连续发送会触发 10 秒冷却， 所以必须图文分条、每条间隔发送）。天气节点是纯文本，只发文字不发图。 

{{ hermes_prompt }}
用怎么用
  • 早报在微信 / 飞书 / TG 对 Hermes 说「早报」——立即收到今天的早报（图文分条）
  • 早报 2026-10-07说「早报 + 日期」——收指定那天的成品
  • 早报任务说「早报任务」——列出当前配置好的早报节点（名称 + 类型 + 条数）
  • 早报配置说「早报配置」——它会引导你到本页面的早报配置调整流水线

图文数据源：文字 /api/brief（每个节点的 text 字段）· 图片 /api/brief/image?section=N（服务端渲染的 1080px 长图；weather 节点无图）。 流水线节点在 早报配置 里管理。

{# ── MCP ── #}
MCP · 填一段配置，多个工具

项目自带一个零依赖的 stdio MCP server（scripts/smtm_mcp.py）， 提供 get_brief（早报精选）、list_articles、get_article、 get_daily_report、search_articles 五个工具。 在支持 MCP 的客户端里加这段配置： 

{
  "mcpServers": {
    "show-me-the-money": {
      "command": "python3",
      "args": ["/path/to/show-me-the-money/scripts/smtm_mcp.py"],
      "env": { "SMTM_BASE": "{{ base }}" }
    }
  }
}

{# ── 早报 ── #}
早报 · 精选 TOP N 的成稿文本

早报是按你配置好的规则（分类 / 主题 / 标签 / 关键词）精选的 TOP N 条， 内容直接继承每篇文章的早报片段 —— 不用给文章再做一次汇总。 Agent 问「今天有什么重要的事」时读它最快。 

curl {{ base }}/api/brief | jq .text

规则调整在 早报配置 页；纯文本 /brief.txt、 Markdown /brief.md 打开即读。
